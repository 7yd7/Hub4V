# 7yd7 Hub UI Guide & Definitions

هذا الملف يوضح لك أنواع الـ Elements المتاحة وكيفية استخدامها في ملفات الـ JSON.

---

## 1. العناصر الأساسية (Elements Types)
تستخدم داخل مصفوفة `Elements` في كل Tab.

- **Paragraph**: لعرض نصوص توضيحية.
  - `Title`: العنوان.
  - `Content`: النص.
- **Button**: زر لتنفيذ أمر معين.
  - `Title`: اسم الزر.
  - `Description`: وصف بسيط تحت الاسم.
  - `Script`: كود Luau يتم تنفيذه عند الضغط.
- **Toggle**: مفتاح تشغيل/إيقاف (On/Off).
  - `Title`: الاسم.
  - `Default`: الحالة الافتراضية (true/false).
  - `Script`: الكود (متغير `Value` يحمل الحالة الجديدة).
- **Slider**: شريط سحب لاختيار الأرقام.
  - `Title`, `Min`, `Max`, `Default`, `Rounding`.
- **Input**: حقل لإدخال النصوص.
  - `Title`, `Placeholder`, `Default`.
- **Dropdown**: قائمة منسدلة للاختيار.
  - `Title`, `Values` (مصفوفة خيارات), `Multi` (تعدد الاختيار).

---

## 2. الإضافات الخاصة (Extra / Sectioning)
هذه الخصائص توضع على مستوى الـ **Tab** نفسه وليس الـ Element.

- **SectionTitle**:
  - **الوظيفة**: يقوم بإنشاء "قسم" (Section) داخل الـ Tab.
  - **WindUI**: يضع العناصر داخل مربع مقسم بعنوان.
  - **NOTHING**: ينشئ قسماً جديداً.
- **SectionIcon**:
  - **الوظيفة**: أيقونة للقسم (تعمل بشكل أساسي في NOTHING و WindUI).
- **iconLogo**:
  - **الوظيفة**: أيقونة إضافية لنافذة الـ WindUI تظهر في الأعلى.

---

## 3. الفرق بين الـ UIs
كل مكتبة واجهة تتعامل مع هذه الخصائص بشكل مختلف:

| الخاصية | Fluent | WindUI | Rayfield | NOTHING |
| :--- | :--- | :--- | :--- | :--- |
| **Icons** | يدعم Luau icons | يدعم Solar icons | يدعم Numerical IDs | يدعم Numerical IDs |
| **Sections** | لا يدعم (كل Tab مسطح) | يدعم (داخل الـ Tab) | يدعم (عبر الـ Elements) | يدعم (كتقسيم أساسي) |

---
*ملاحظة: دائماً ابدأ كود الـ Toggle بـ `if Value then ... else ... end` للتحكم في التشغيل والإيقاف.*
